# ✈️ Air Ticket Tanzania

Air Ticket Tanzania is a simple flight booking platform built using HTML, CSS, and JavaScript. 
The platform allows users to browse available flights, book tickets, and manage their bookings through an easy-to-use interface.

## 🌟 Features

### 🛫 Flights
- View available flights
- Check flight details
- Browse destinations

### 🎫 Booking
- Book flight tickets
- Enter passenger information
- Receive booking confirmation

### 📋 My Bookings
- View booked tickets
- Manage reservations
- Check booking details

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/fredy-Mussa/Air-Tanzania.git
```

2. Open the project folder:

```bash
cd air-ticket-tanzania
```

3. Open `index.html` in your browser.

No additional installation is required.

## 💡 How It Works

1. Browse available flights.
2. Select a flight.
3. Complete the booking form.
4. View your bookings in the **My Bookings** section.
